## Approved claims

- `CLM-0027`: PCC adopts a seven-part Chapter 2 architecture that places
  bounded actor-indexed Theory of Mind beneath public grounding, public-warrant
  promotion, action-sensitive interpretation comparison, situated work
  context, and contestable diagnostic output.
- `CLM-0028`: PCC targets cases in which an action-relevant interpretation
  appears to have entered coordination state without sufficient visible public
  evidence, including cases in which no overt repair sequence begins.
- `CLM-0029`: PCC restricts pragmatic analysis to plausible contextual
  interpretations whose adoption would materially change a downstream
  coordination action.
- `CLM-0030`: A coordination-critical variable is a task variable for which
  plausible competing values imply materially different plans, permissions,
  schedules, responsibilities, resources, artifact states, or completion
  criteria.
- `CLM-0031`: PCC treats public warrant as a defeasible judgment about whether
  visible evidence is sufficient to promote an interpretation into
  action-guiding coordination commitment.
- `CLM-0032`: PCC uses organizational role, authorization, resource, artifact,
  and workflow state as situated evidence governing whether an interpretation
  is action-ready, rather than treating dialogue alone as sufficient proof of
  uptake.
- `CLM-0033`: A PCC diagnostic is intended to expose the relevant variable,
  competing interpretations, attributed evidence, warrant judgment,
  uncertainty, and downstream action difference so that a human reviewer can
  contest the diagnosis.
- `CLM-0034`: PCC’s bounded residual is an evaluation target combining
  attributed actor state, public evidence, a defeasible promotion judgment,
  situated role and artifact governance, action-sensitive consequences,
  abstention, and a contestable diagnostic record; no verified priority claim
  is made.
