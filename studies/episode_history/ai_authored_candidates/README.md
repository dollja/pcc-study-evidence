# AI-authored candidate inventory: author acceptance

Registration version **0.1.1** records an author decision about the unchanged
episode corpus **0.1.0**. This directory is metadata only, not a corpus release.

## Decision and reviewer

`DEC-0025` records the author's instruction on **2026-09-13** to accept all
30 candidate episodes. `author_review` identifies the requesting author as
decision-maker; ChatGPT transcribes the instruction. No independent reviewer,
criterion-level rationale, signature, or review duration is inferred.

In `acceptance_review_register.csv`, the five `author_*` columns hold the
acceptance, reviewer role, decision date, reason, and decision ID for every
episode. The shared reason records the actual basis: an author instruction,
not invented episode-specific findings.

The original columns, including `human_acceptance`, `reviewer_id`, `review_date`,
`decision`, and all substantive review fields, are unchanged. They remain
reserved for the separate material-review procedure. The exact original CSV
is retained in `history/acceptance_review_register.v0.1.0.csv`.

## Boundaries

Author acceptance is complete for candidate retention. Independent material
acceptance, independent rule review, and privacy-release review remain pending.
No participant-use or public-corpus-release permission is recorded. No
annotations, detector predictions, or benchmark evaluations are added.

The corpus remains one AI-authored, source-inspired collection. It is not
independently human-authored and is not automatically pooled with the ACS

independent pilot, or later main evaluation.

No episode text, rule-pack text, original source material, source mappings,
full authoring histories, or private participant/reviewer details are included.
Package and manifest checksums bind the decision to the retained source bytes.
A checksum establishes identity, not privacy clearance or review quality.

This is an additive registration, not a modified corpus release. Episode and
rule bytes and their 0.1.0 versions are unchanged. A later text, rule, cutoff,
or event change requires a new content version and review of affected items.
Record actual independent reviews separately; never rewrite this author
decision as if those reviews had already occurred.

The active workflow, claims, novelty registers, scholarly evidence, existing
PEV statuses, and independent-pilot/main-evaluation manifests are unchanged.
Validation of these metadata does not close a research or privacy gate.
